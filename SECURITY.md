# Security Policy

## Reporting a vulnerability

If you find a security issue on Suprpod, please report it privately. Don't post it in Issues or Discussions.

Use [private vulnerability reporting](../../security/advisories/new) on this repo.

Please include:

- What you found and where (page or URL)
- Steps to reproduce it
- What an attacker could do with it

## What to expect

- We'll acknowledge your report within 72 hours.
- We'll keep you updated while we investigate and fix it.
- With your permission, we'll credit you once it's resolved.

Please give us reasonable time to fix the issue before sharing it publicly, and don't access or modify other users' data while testing.
